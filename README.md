# Проект **homewrk**
## Описание:
Проект homework - это виджет для выполнения некоторых банковских операций.
## Установка:
Клонируйте репозиторий:
```
git clone git@github.com:Otez404/homework.git
```
## Использование:
В проекте есть 4 функциональных модуля:
### 1 модуль
В модуле **masks.py** реализованы функции маскировки номера карты и банковского счета
Для использования функции введите номер банковской карты или номер счета в виде: **7000792289606361** (16 цифр),
**73654108430135874305** (20 цифр)
### 2 модуль
В модуле **wiget.py** реализованы функции объединения функций в модуле masks.py, а также функция изменения формата даты
Для использования функции введите номер банковской карты или номер счета в виде: **Visa Platinum 7000792289606361**,
**Счет 73654108430135874305**  
Дату в формате : "2024-03-11T02:26:18.671407"
### 3 модуль
В модуле **processing.py** реализованы функции возращения списка словарей по опциональному значению ключа и сортировки списка словарей по дате  
Для использования функции передайте список словарей :  
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
{'id': 939719570, 'state': 'EXECUTED','date': '2018-06-30T02:08:58.425572'},
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
### 4 модуль
В модуле **generators.py** реализованы итераторы фильтрации транзакций по валюте, по описанию транзакции, генератор номера банковских карт
### 5 модуль
Модуль **decorators.py** автоматически регистрирует детали выполнения функций, такие как время вызова, имя функции, передаваемые аргументы
## Тестирования: 
Проект покрыт юнит-тестами. Для их запуска выполните команду: pytest
